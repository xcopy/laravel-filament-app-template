# Laravel Filament App Template

A lightweight Laravel + Filament starter for building admin-driven apps.

## Includes

- Laravel 13 and PHP 8.3
- Filament 5 admin panel
- Role and permission management
- Media uploads and file handling
- User audit/stamp tracking

## Quick start

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan serve
```

Then open http://localhost:8000.
